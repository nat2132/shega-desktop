# i18n Translation Completion Plan

## Goal
Translate all remaining hardcoded English UI strings into `t()` calls across ~11 files (~89 strings), adding ~39 new translation keys to `translations.ts`.

## Phase 0: Shared Infrastructure — Month/Day Abbreviations

Add month abbreviation keys to `budgets` namespace and day abbreviation keys to `analytics` namespace in `translations.ts` (all 4 languages). These are reused across 4+ files.

**New keys:**
- `budgets.month_jan` through `budgets.month_dec` (12 keys)
- `analytics.day_sun` through `analytics.day_sat` (7 keys)

**Usage pattern:**
```ts
const monthAbbr = [t('budgets.month_jan'), t('budgets.month_feb'), ...];
const dayAbbr = [t('analytics.day_sun'), t('analytics.day_mon'), ...];
```
